# 📝 To-Do List Application

A simple, elegant, and functional to-do list app with local storage functionality.

## Features ✨

- ✅ **Add Tasks**: Easily add new tasks to your list
- ✅ **Mark Complete**: Check off tasks as you complete them
- ✅ **Delete Tasks**: Remove individual tasks
- ✅ **Filter Tasks**: View All, Active, or Completed tasks
- ✅ **Local Storage**: Your tasks are saved and persist between sessions
- ✅ **Statistics**: See total and completed task counts
- ✅ **Responsive Design**: Works on desktop and mobile devices
- ✅ **Beautiful UI**: Modern gradient design with smooth animations

## How to Use 🚀

1. **Open** `index.html` in your web browser
2. **Type** your task in the input field
3. **Click** "Add Task" or press Enter
4. **Check** the box to mark tasks as complete
5. **Delete** tasks with the Delete button
6. **Filter** tasks using the filter buttons
7. **Clear** all completed tasks at once

## Key Features Explained 📚

### Local Storage
Tasks are automatically saved to your browser's local storage. This means:
- Your tasks persist even if you close the browser
- Each browser/device has its own separate task list
- No server or database required

### Filtering
- **All**: Shows all tasks
- **Active**: Shows only incomplete tasks
- **Completed**: Shows only completed tasks

### Statistics
- **Total**: Count of all tasks
- **Completed**: Count of finished tasks
